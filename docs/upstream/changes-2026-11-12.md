## Feature differences

- Conversation rename: chosen title wins over generated summary; clearing restores it. Native implementation added, including persistence and UI tests. All local conversations belong to this device owner; team ownership is not implemented.
- Routines: unified goal/routine editor, New routine navigation, hourly prose labels, typed timezone refusal; ends_when_met and goal_linked_by_run lifecycle changes. Hourly labels and refusal code are ported; unified editor/lifecycle work remains.
- Approval changes: conversation-scoped answers, open-by-default standing answers, admin closed rules, plain-language rules/backtesting/audit/auto-review guidance. Only updated unrun-outcome wording is ported in this phase; the older conservative policy remains until the entire policy transition can be validated together.
- Dictation: microphone on every composer with on-device fallback, notices outside starter tasks and stable composer layout. API transcription exists; on-device fallback remains to port.
- Reliability: keep parallel tool results when reopening, recover broken live streams from stored runs, one run for a first message, run budgets/promise handling, endpoint tools reads-first and common prompts. Native durable checkpoints exist; runtime semantics require per-module review.
- UI/copy: Inter typeface, solid sidebar, slowly pulsing working text, model-picker focus/levels, consistent Bot orb, Cards/rendered budgets and global navigation changes. Native typography still uses the earlier Atkinson font; full visual parity is not claimed.
- Providers/accounts: Claude plan and Grok sign-in model discovery; Composio app sign-in; team/admin natural-language policy controls and Learning changes remain absent in the local Android architecture.
- Desktop/deployment: numerous macOS/Windows Docker/Podman/WSL/update/install/diagnostic fixes, Intelligence/chart upgrades, CI runner changes and Kubernetes documentation. These are not phone backend implementations.
- Computer/browser automation: serialized browser actions, form reading and activity panel changes are deliberately excluded by the requested Android scope.
