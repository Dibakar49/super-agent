# Kotlin Android migration ledger

This is a staged native implementation, not a completed same-behavior port.
The requested target is an Android phone with its backend and agents running locally.
Computer use is explicitly excluded. No remote OpenBot server is used by the new app.
Local backend does not require a local language model: provider API calls and
optional on-device inference are separate modes.

## Validation boundaries

Build/test results must be recorded after execution. A compiled APK is not proof
of on-device inference or feature parity. MediaPipe requires an actual compatible
`.task` model and compatible Android hardware. No model is bundled or silently
downloaded. Imported models stay in app-private storage. The app uses Internet for configured HTTPS model and MCP endpoints, and network
state to defer provider routines while offline. Provider inference dispatches local
routine/memory tools; on-device inference currently performs text turns. External-app
actions are wired through granted MCP tools and original approval policy. OAuth remains pending.
